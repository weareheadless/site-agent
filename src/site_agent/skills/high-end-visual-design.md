# High-End Visual Design (condensed from leonxlnx/taste-skill)

Make it feel expensive. Expensive = restraint, precision, and one confident gesture.

## The rules that separate agency from template
- One typeface pairing, executed with discipline: expressive serif/display + neutral sans. Vary SIZE and WEIGHT, never add fonts.
- Kill default shadows. Depth comes from layering surfaces (bg tones) or a single soft large-radius shadow (0 20px 60px rgba(0,0,0,.12)) — never 4px gray borders everywhere.
- Radius consistency: pick one radius language (all 999px pills, or all 8–12px) — mixing reads cheap.
- Icons: one set only, consistent stroke weight, sized to text x-height.

## Spacing is the luxury
- Double the whitespace you think you need between sections; halve the number of elements per section.
- Optical alignment beats mathematical alignment: optically center icons in circles, nudge caps-height to baseline.

## Color like money
- Near-black ink on warm off-white (or deep navy/space-black with ivory text), ONE metallic/gem accent used <5% of the page.
- Never pure #000/#fff pairs; never saturated primary backgrounds behind body text.
- Borders are rgba() hairlines at 12–18% opacity, not solid grays.

## Imagery & texture
- Photography: consistent treatment (same filter/duotone/grain). One full-bleed hero image > four thumbnails.
- Subtle grain overlay (3–5% opacity) unifies flat gradients into "printed" surfaces.

## Copy & micro-details
- Sentence-case buttons, no exclamation marks, no "Welcome to our website".
- Numbers get tabular figures; dates/currencies formatted consistently; footer carries the same care as the hero.
